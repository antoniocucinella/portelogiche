# NOME PROGETTO

Descrivi qui in due righe cosa fa il laboratorio.

## Cartelle

```
index.html   la pagina (contiene già il pulsante "Laboratori" per tornare alla home)
css/         l'aspetto
js/          il comportamento (file numerati: 01-, 02-, ...)
data/        dati modificabili senza toccare il codice (es. esercizi.json)
```

I percorsi nei file sono **relativi** (`css/stile.css`, `js/...`): non cambiarli in assoluti,
così la cartella si può spostare senza rompere nulla.
Per le risorse condivise con la home usa `../../assets/...`.
